# Seguridad / Security

## Cómo informar de una vulnerabilidad

**Por favor, no abras una incidencia pública para una vulnerabilidad.** Usa el informe privado de GitHub (pestaña **Security → Report a vulnerability** de este repositorio) o escribe a <contact@majixlab.com> con el asunto «Seguridad MAJIX Tools».

Incluye, si puedes: la versión, los pasos para reproducirlo y el impacto que crees que tiene. Te responderemos lo antes posible, te mantendremos informado de la corrección y, si lo deseas, te mencionaremos al publicarla.

## Qué consideramos en el alcance

- Que el token de sesión (`mjxt_…`) llegue al navegador, a un registro o a un fichero del proyecto.
- Que el plugin responda a peticiones de otra web, de otro equipo o sin la cabecera exigida.
- Que se envíe a MAJIX algo que no figure en la lista de «Privacidad» del README.
- Que quede cualquier rastro de MAJIX Tools en una compilación de producción.
- Cualquier lectura de ficheros fuera de la raíz del proyecto.

## How to report a vulnerability

**Please do not open a public issue for a vulnerability.** Use GitHub's private report (**Security → Report a vulnerability** tab of this repository) or write to <contact@majixlab.com> with the subject “MAJIX Tools security”.

Include, if you can: the version, the steps to reproduce it and the impact you believe it has. We will answer as soon as possible, keep you informed of the fix and, if you wish, credit you when it is published.
